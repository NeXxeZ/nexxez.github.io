Place the reviewed 16:9 screenshots here using these exact filenames:

- `dam-sport.png`

- `optica-bassol.png`
- `sara-aguilar.png`

The HTML references this directory directly. If a PNG is missing, the image element falls back to the corresponding SVG placeholder in `assets/img/projects/`.

Run `./scripts/capture-projects.sh` to generate screenshots with Chromium where possible. For sites protected by Cloudflare, capture manually in a normal browser session and save the PNG here.
